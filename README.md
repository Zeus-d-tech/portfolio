# Arzeus Arayata — Personal Portfolio

Personal developer portfolio built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite** for **DCIT 26: Application Development and Emerging Technologies** at Cavite State University — Bacoor City Campus.

## Sections Included

- **Home**: Brand identity, hero showcase, tagline, and academic summary metrics.
- **About**: Student profile (`BSCS 3-2`, Las Piñas City), background narrative, and filterable technical skills with practical application examples.
- **Projects & Certificates**: Featured case study for **Coolect: Eco-Friendly Smart Cooling System**, interactive project inspection modal, and verified certificates gallery.
- **Deployment & Maintenance Plan**: Hosting configuration and ongoing update schedule.
- **Contact**: Direct email copy-to-clipboard, social links, and a validated contact form.

## Tech Stack

- React 19 & TypeScript
- Tailwind CSS v4 (Grid, Flexbox, responsive breakpoints)
- Vite
- Lucide Icons

## Local Development

```bash
npm install
npm run dev
```

## Production Build

npm run build
